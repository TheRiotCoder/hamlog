      Upload to QRZ.com

      0 QSOs not yet uploaded.

      Set My callsign in Settings first. It is exported as STATION_CALLSIGN and should match your QRZ logbook's callsign.
      1. Save the ADIF file with your new QSOs.

        On iPhone choose Save to Files; on Android it goes to Downloads (or pick Drive / Files in the share sheet).

      2. Open your QRZ Logbook and sign in (a free QRZ account works).
        Open logbook.qrz.com ↗
      3. Import the file: in your QRZ Logbook open Settings and click Import under “ADIF Import/Export” (or use the Import/Export Tools button at the top right → Import from ADI File). Tap Choose File, pick the .adi file you saved, then Import ADI File. QRZ processes imports in the background – give it a minute, then refresh your logbook.
      4. Confirm: once the QSOs show up on QRZ, mark them as uploaded so the next export only contains new ones.

      Upload status tools

      Use these if HamLog and QRZ got out of sync.

      QRZ treats an imported QSO with the same call, band and mode within ±30 minutes as a duplicate: it replaces the existing record (confirmed records are left alone), so re-uploading does not create double entries.
