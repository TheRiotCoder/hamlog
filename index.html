        If you leave a password box empty, the saved password stays as it is. A password manager can fill these forms.

        Encryption, auto-lock & backup

        Without a passphrase, logins are kept for this tab only (session-only) and are gone when it closes. With one, they're encrypted (AES-GCM; key from PBKDF2-SHA256, 600,000 rounds) and saved on this device.

        The backup file is encrypted with this passphrase. Logins are never exported in plain text, and they're not in the normal JSON log backup.
